# LyriQ

LyriQ is a full-stack lyric-matching game developed as a collaborative
software development project.

## Features

- Generates randomized 12-word lyric challenges
- Supports up to 10 songs per artist
- Gives players 3 attempts per round and 5 lives
- Provides progressive album and song hints
- Uses difficulty-based scoring
- Maintains game state using Django sessions
- Responsive 3-column interface

## Technologies

- Python
- Django
- PostgreSQL
- JavaScript
- HTML & CSS
- Bootstrap
- Docker
